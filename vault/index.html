How to play

Everyone gets the same 4-digit code today. Guess it in 6 tries.

🟩 Green: right digit, right spot. 🟨 Yellow: right digit, wrong spot. ⬛ Black: not in the code.

Each digit 0–9 is used at most once in the code, but you can type any digits you like in a guess.
