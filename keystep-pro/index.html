Library Saved patterns

Saves the notes themselves, not just the seed. The generator keeps changing, so a stored recipe would replay differently later — these will not.

Ensemble Four parts, drifting lengths (polymeter)

Independent track lengths make the parts drift against each other. The generator writes each part knowing where the others already sit, so they interlock instead of stacking up.

Polyrhythm Conflicting pulses in the same span

Two or more voices dividing the same time differently: three evenly spaced notes against four, starting together, finishing together, disagreeing throughout. Voices are kept deliberately plain — if every part is a tune, three against four just sounds like a mess.
